# 李元이 하직함

- 번역 모델: MiniMax-M2.7

### 한글 번역

하직한다. 통원수 이원. 내하일기(승정원일기)

### 독음

하직, 도원수 이원. 내하일기

### 의미

인조 11년 3월 2일, 통원수(都元帥) 이원이 관직에서 하직하였다. 승정원일기에 기록된 간략한 인사 변동 사항으로, '하직'은 해당 직무에서 물러남을 의미한다. '내하일기'는 승정원일기의 표기 방식으로, 승정원 관원이 작성한 일기라는 뜻이다.
