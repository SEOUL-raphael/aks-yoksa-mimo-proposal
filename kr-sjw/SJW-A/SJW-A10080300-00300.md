# 李領府事에게 米太와 饌物을 賜給하라는 전교

- 번역 모델: MiniMax-M2.7

### 한글 번역

전교하기를, 이，领府事에게 해당 관원이 미태와 찬물을 하사하도록 명하였다.

### 독음

전일, 이，领府事에게 명하여 해당 관원으로 하여금 미태와 찬물을 하사하게 하였다.

### 의미

인조 10년 8월 30일 왕이 이，领府事에게 곡물과 음식을 하사하는 명령을 내렸다. 승정원이 해당 관서에 전달하는 전교 형식으로, 受俸자에게俸禄 외에 특별히 식료품을 내리는 내용이다. 李은 성, 領府事는 정1품 벼슬인 領中枢府事로 추정된다.

### 원문

```text
○ 傳曰, 李領府事處, 令該官米太饌物賜給。
```
