## 昌慶宮에 머묾。常參과 經筵을 정지함

- 기사 ID: `SJW-A18030020-00100`
- 출처: https://sjw.history.go.kr/id/SJW-A18030020-00100

### 한글 번역

임금님께서 창경궁에 계시며, 상참과 경연을 정지하시다.

### 독음

상재창경궁 정상참경연

### 의미

인조 18년(1640년) 3월 2일, 임금(인조)이 창경궁에 거처하면서 평소의 상참과 경연을 모두 중단하였다. 상참은 임금이 신하를 만나 여러 안건을 처리하던 일상 업무 의례이고, 경연은 유교 경전에 대한 강연을 듣고 토론하던 교육 겸 정사 의례였다. 임금이 창경궁에 머물렀다는 사실은 비상시의 거처 변경을 의미하며, 상참·경연의 정지는 다른 사정이 있었음을 보여준다.

### 원문

```text
○ 上在昌慶宮。停常參·經筵。
```

## 잠시 왕래하는 사람에게 말을 보낸 해당 堂上 등을 推考하라고 備局의 草記에 대해 내린 비답

- 기사 ID: `SJW-A18030020-00200`
- 출처: https://sjw.history.go.kr/id/SJW-A18030020-00200

### 한글 번역

비국 초기에 대한 답으로, 잠깐 왕래하는 사람에게 사마를 허공으로 보내는 것은 극히 부당하니, 해당 당상과 랑청을 추고한다.

### 독음

답 비국 초기 왈, 잠 위 왕래 지인, 사마 허송, 극 위 부당, 당 해당 당상 랑청 추고.

### 의미

인조 18년 3월 2일, 국왕이 비국(備局)의 초기에 답하는 형식으로 내린 비답이다. 잠시 방문하는 사람에게 특별한 필요 없이 사마(私馬)를 보내는 것이 극히 부당하다는 판단之下, 해당 당상과 랑청两级관을 추고(推考·심사)하라는 지시를 내렸다. 이른바 '私馬虛送'은 공적 말을 사적으로 빈 전송한 것으로, 관용 남용에 대한 견제가 포함된 조치이다.

### 원문

```text
○ 答備局草記曰, 暫爲往來之人, 私馬虛送, 極爲不當, 當該堂上郞廳推考。
```

## 諸臣에게도 贈物하라고 戶曹의 草記에 대해 내린 비답

- 기사 ID: `SJW-A18030020-00300`
- 출처: https://sjw.history.go.kr/id/SJW-A18030020-00300

### 한글 번역

호조의 초기에 답하여 말하기를, 여러 신하들에게도 또한 선물 증물을 할 것이라, 어쩌면 합당할 듯하다고 하였다. 내림하여 호조에 내려보냈다.

### 독음

답 호조 초기 왈, 제신 처, 역위 증물, 사과의니 내하 단초

### 의미

인조 18년 3월 2일, 호조(戶曹)에서 여러 신하들에게도 선물(증물)을 줄 것을 건의하는 초기를 올렸다. 인조가 이에 대해 '어쩌면 합당할 듯하다'고 유보적이면서도 긍정적인 비답을 내렸다.

### 원문

```text
○ 答戶曹草記曰, 諸臣處, 亦爲贈物, 似可矣。內下記草
```
