# 韓興一에게 관직을 제수함

### 한글 번역

政务을 베푸다. 한흥일을 부수선으로 임명하다.

### 독음

유정. 한흥일 를 부수선으로 삼다.

### 의미

인조 7년 12월 30일, 정부政务이 베풀어져 한흥일을 부수선에 임명하였다. 부수선은 사관(史館)에 소속된史官으로,修撰를 보좌하는 정5품 관직이다.

### 원문

```text
○ 有政。以韓興一爲副修撰。
```
