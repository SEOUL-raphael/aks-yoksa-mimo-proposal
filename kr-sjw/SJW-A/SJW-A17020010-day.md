## 昌慶宮에 머묾。常參과 經筵을 정지함

- 기사 ID: `SJW-A17020010-00100`
- 출처: https://sjw.history.go.kr/id/SJW-A17020010-00100

### 한글 번역

임금님께서 창경궁에 거처하시며, 상참과 경연을 모두 중지하셨다.

### 독음

상재창경궁 정상참경연

### 의미

인조 17년 2월 1일, 인조는 창경궁에 거처하면서 일상 조회를 주관하는 상참과 경서를 강독하는 경연을 모두 중단시켰다. 이는 환관이나 유학 등 특정 세력과의 충돌, 질병, 또는 국가 운영의 일시적 중단을 의미하는 조처로 볼 수 있다.

### 원문

```text
○ 上在昌慶宮。停常參·經筵。
```

## 宣祖大王의 忌辰

- 기사 ID: `SJW-A17020010-00200`
- 출처: https://sjw.history.go.kr/id/SJW-A17020010-00200

### 한글 번역

선조 대왕의 기신(사망일).

### 독음

선조대왕 기신

### 의미

인조 17년(1639년) 2월 1일 선조 대왕의 기신(사망일을 기리는 명절의 날)을 시행하였다. 선조 대왕은 1608년 3월(음력 2월)에 붕어하였으므로, 음력 2월 초一日을 기신으로 지내고 있음을 보여주는 기 록이다. 기신은 명절의 하나로서 해당 날에 제사를 지내고 관서에서는 이를 관보에 공식 게시하였다.

### 원문

```text
○ 宣祖大王忌辰。
```

## 流星이 나타남

- 기사 ID: `SJW-A17020010-00300`
- 출처: https://sjw.history.go.kr/id/SJW-A17020010-00300

### 한글 번역

오경(새벽 3~5시) 때, 유성이 관삭성 아래에서 나와 호과성 위쪽으로 들어갔다. 모양은 그릇(钵)과 같았고, 꼬리 길이가 약 오륙尺(약 1.5~1.8미터) 정도이며, 색은 희었다.

### 독음

오경, 유성 출관삭성하, 입호과성상, 상황여발, 미장오륙척허, 색백.

### 의미

인조 17년 2월 1일 새벽, 하늘에서 유성이 관측되었다. 관삭성 아래에서 호과성 쪽으로 날아가는 유성이 모습을 드러냈으며, 크기는 그릇만 하고 꼬리는 약 1.5~1.8미터 정도의 희白色이었다. 당대에는 이러한 천체 현상을 일상적 관측 기록으로 남겼다.

### 원문

```text
○ 五更, 流星出貫索星下, 入匏瓜星上, 狀如鉢, 尾長五六尺許, 色白。
```

## 備邊司의 계

- 기사 ID: `SJW-A17020010-00500`
- 출처: https://sjw.history.go.kr/id/SJW-A17020010-00500

### 한글 번역

비변사(備邊司)에서 계문하였다. 답하기를, '명나라의 척사가 올 때에는 이 사람(통역관)도 반드시 따라올 것이므로, 그때 주더라도 늦지 않다. 두 명의 통역관에게 은전을 지급하는 일'

### 독음

비변사 계. 답하기를, 척사가 출래할 때, 이 사람도 반드시 수래하겠으니, 그때 주어도 미晚了지 않다. 양역에게 은을 주는 일을.

### 의미

비변사는 명나라 사신(척사) 방문 시 통역관이 함께 올 것이므로, 현재가 아닌 그때 은전을 줘도 늦지 않다는 의견을 계문하였다. 비변사가 제기한 두 통역관에 대한 은급 지급 건에 대해 척사 종사관을 겸임하는 통역관의 수당 지급 시기를 명사 방문 시점으로 미루자는 논의이다.

### 원문

```text
○ 備邊司啓。答曰, 勅使出來時, 此人亦必隨來, 其時給之未晩。兩譯給銀事
```

## 兵曹의 계

- 기사 ID: `SJW-A17020010-00600`
- 출처: https://sjw.history.go.kr/id/SJW-A17020010-00600

### 한글 번역

병조에서 아뢨다. 임금이 답하기를, ‘권하한 바에 의거한다. 군사 운용의 일에 대해서는 다음 차례가 도착하면 방어군을 사용하면 좋겠다.’ (임금이 직접 내려) 일기에 적었다.

### 독음

병조계. 답일, 의계. 용군일사, 후반지, 방군용지, 가야. 내하일기

### 의미

병조의 건의에 대해 임금이 ‘의거한다(승인)’고 답하고, 후번 도착 시 방군을 사용하면 좋겠다는 지시를 내렸다. ‘內下日記’는 왕이 직접下令하여 일기에 기록한 사항임을 나타낸다.

### 원문

```text
○ 兵曹啓。答曰, 依啓。用軍一事, 後番至, 防軍用之, 可也。內下日記
```
