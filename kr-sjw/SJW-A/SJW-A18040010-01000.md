# 申景琥를 兵使로 林慶榮을 軍官으로 정해 하루 이틀안에 發送하라는 비망기

### 한글 번역

비망기로 박수홍에게 전교하였다. 신경호를 병사로, 임경영을 군관으로 임명하고, 이미 정한 바와 같이 하루 이틀 안에 발송할 것임을 해당 부서에 알려줄 것.

### 독음

비망기로 박수홍에게 전교하기를,申景琥는 병사로,林慶榮은 군관으로,이미 정한 바와 같이 하루 이틀 안에 발송할 것임을 해당 부서에 알려라.

### 의미

인조 18년 4월 1일, 임관 林慶榮을 군관으로 삼고, 신경호를 林慶榮의 上官인 兵使로 임명하여 하루 이틀 이내에 출병시키라는 비망기. 承政院에서 兵曹에 전달한 신속 처리 지시로, 林慶榮의 군사 임무 수행을 위한 인력 편성安排的 내용이 담긴 짧은 전결记事.

○ 以備忘傳于朴守弘曰, 申景琥兵使, 林慶榮軍官, 曾定一二日內發送事, 言于該曹。
