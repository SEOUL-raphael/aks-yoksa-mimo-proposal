## 昌慶宮에 머묾。常參과 經筵을 정지함

- 기사 ID: `SJW-A21070300-00100`
- 출처: https://sjw.history.go.kr/id/SJW-A21070300-00100

### 한글 번역

임금이 창경궁에 거재하시니, 상참과 경연을 정지하다.

### 독음

상재 창경궁. 정상삼·경연.

### 의미

인조 21년(1643년) 7월 30일, 임금이 창경궁에 머물면서 정기적인 아침 경연(상참)과 서적 독서 강습(경연)을 모두 중단하였다. 당시 임금이 특정 궁궐에 거재하면 예속 관료의 참배가 어려워 상참과 경연을 열지 못하였다.

### 원문

```text
○ 上在昌慶宮。停常參·經筵。
```

## 교체하여 瀋陽에 들어가는 軍牢 7名에게 각각 布 1疋을 보내줌

- 기사 ID: `SJW-A21070300-00200`
- 출처: https://sjw.history.go.kr/id/SJW-A21070300-00200

### 한글 번역

교체되어 심양에 들어가는 군사죄수 일곱 명에게, 각각 베 한 필씩 나누어 주어 보냈다. 내일기

### 독음

교체 입심군칠 명, 각 부일필급송. 내일기

### 의미

인조 21년 7월 30일, 교체 인원으로 심양(만주)에 파견되는 군사죄수 7명에게 각각 베 1필씩을 제공한 기록이다. 심양은 후금(，清)의 근거지로서, 이 시기 조선은 명 왕조의 속방이었으나 만주와 외교·통상 관계를 유지하고 있었다. 군사죄수에게 여비를 마련하는 차원의 물자 지급 사안으로, 왕실 기로소의 내부 기록인 내일기에 편입된 사항이다.

### 원문

```text
○ 交替入瀋軍牢七名, 各布一疋給送。內日記
```

## 受鍼하고 藥을 복용한 뒤에 증세의 차도 등에 대해 묻는 藥房의 계

- 기사 ID: `SJW-A21070300-00300`
- 출처: https://sjw.history.go.kr/id/SJW-A21070300-00300

### 한글 번역

약방 도제조인 좌의정 심기원, 제조인 호조판서 이명, 부제조인 행도승지 김윤이 아뢴다. 밤사이 깊이 존중하니, 폐하의 증후는 어떠합니까? 침 시술을 받고 약을 복용한 뒤에 여러 증세의 호전과 악화는 어떻습니까? 가을 더위가 아직 가시지 않았고, 날씨가 여전히 음습한 기색이 있으니, 밤사이 잠의 상태는 어떠합니까? 소신들이 극도로 걱정하여, 감히 이에 안부를 여쭙나이다. 회하, 변화가 없습니다.

### 독음

약방도체조신 좌의정 심기원, 체조신 호조판서 이명, 부체조신행 도승지 김윤 계일, 야래복미심, 성후약하, 수전진약지후, 제증감감여하, 추열미퇴, 일기상이음울지후, 야간침수지절, 역여하, 신등불승전려지지, 감차문안.

### 의미

인조 21년 7월 30일, 약방 소속 관리들이 임금의 건강 상태를 살피는 정기적인 문안 계를 올렸다. 좌의정 심기원, 호조판서 이명, 도승지 김윤이 각각 도제조, 제조, 부제조 직책으로 참여했다. 침 시술과 약 복용 후 증세 변화를 묻고, 가을철 습기운이 아직 남아있음을 이유로 잠 상태도 문안했다. 임금은 증상에 변화가 없다고 답했다.

### 원문

```text
○ 藥房都提調臣左議政沈器遠, 提調臣戶曹判書李溟, 副提調臣行都承旨金堉啓曰, 夜來伏未審, 聖候若何? 受鍼進藥之後, 諸症加減, 如何? 秋熱未退, 日氣尙有陰鬱之候, 夜間寢睡之節, 亦如何? 臣等不勝煎慮之至, 敢此問安。答曰, 時無加減。
```
