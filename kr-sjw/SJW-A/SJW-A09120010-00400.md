# 東西氷庫를 摘奸함

### 한글 번역

동서 빙고 안을 직접 조사했다.

### 독음

동서빙고 내 적간

### 의미

인조 9년 12월 1일에 서울의 동쪽 빙고와 서쪽 빙고의 내부 상황을 직접 점검하였다는 기사이다. 빙고는 겨울에 얼음을 저장하여 여름에 왕실과 관청에 공급하던 시설로, 동서 두 곳에 위치해 있었다.摘奸(적간)은 직접 나가서 문제를 조사하거나 점검한다는 뜻이다. 이 날 구체적으로 어떤 문제가 발견되었는지는 이 짧은 제목 기사만으로는 알 수 없다.

```text
○ 東西氷庫內摘奸。
```
