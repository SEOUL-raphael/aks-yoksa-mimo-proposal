# 안심하고 조리하라는 洪瑞鳳의 상소에 대해 내린 비답

### 한글 번역

좌의정 홍서봉의 상소(疏)에 대하여 다음과 같이 답하였다. (수자缺) 안심하고 조리하라.

### 독음

답 좌의정 홍서봉 소 수자결 안심조리.

### 의미

인조 14년 8월 1일, 좌의정 홍서봉이 건강 회복을 위해 조리하겠다는 상소에 대해 임금이 비답(답변)을 내렸다. '안심하고 조리하라'는 것은 상소인의 건강 상태를 배려하여 쉬어도 좋다는 허락을 의미한다.
