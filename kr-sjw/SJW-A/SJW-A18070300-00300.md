# 朴潢의 첫 번째 呈辭

### 한글 번역

대사간 박황이 첫 번째로 사직서를 올렸다. 사직이 허여되었다.

### 독음

대사간박황초도정사.급유.

### 의미

인조 18년(1640년) 7월 30일, 대사간 박황이 첫 번째 사직서를 제출하여 관직에서 내려오게 되었다. 初度는 해당 관원이 사직서를 올린 횟수를 나타내며, 이것이 첫 번째 사직임을 의미한다. 給由는 왕이 사직서를 받아들여 하사하는 것을 뜻한다. 대사간은 홍문관과 성균관 등의 교관(교수)을 겸임하던 높은 관직이었다.
