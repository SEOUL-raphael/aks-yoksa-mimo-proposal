# 島中의 事情을 일일이 염탐하여 연속 馳啓하도록 金時讓에게 下諭하라고 함

- 기사 ID: `SJW-A07060300-00200`
- 왕대: 인조
- 날짜: 인조 7년(1629년 崇禎(明/毅宗) 2년) > 인조 7년 6월 > 인조 7년 6월 30일 > 島中의 事情을 일일이 염탐하여 연속 馳啓하도록 金時讓에게 下諭하라고 함
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-A07060300-00200

### 한글 번역

섬(일본) 안의 여러 사정을 하나하나 탐색하여 연속으로 말을 달려 보고하라는 칙서를 평안감사 김시양에게 내렸다.

### 독음

도중 범간사정, 일일탐정, 연속치계사, 평안감사 김시양처, 하유

### 의미

인조 7년 6월 30일, 일본 내부의 여러 형편을 하나하나 떠보는 정보를 수집하고, 이를 연속으로 신속히 보고하라는 지시를 평안감사(金時讓)에게 칙서로 내렸다. 일본의 동향을 파악하려는 대마도前沿 군사정보 수집 활동의 일환이다.

### 원문

```text
○ 島中凡干事情, 一一探聽, 連續馳啓事, 平安監司金時讓處, 下諭。
```
