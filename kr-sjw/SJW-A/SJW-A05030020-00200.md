# 李廷龜 등을 引見함

- 번역 모델: MiniMax-M2.7

### 한글 번역

왜인 접대 관리 이정귀와 이경직, 장유를 대궐에 불러 대신과 비보거 당상, 양사(홍문관·의정부) 수장에게 인견(왕의 직접 接見)을 베풀었다.

### 독음

후차접대관 이정귀·이경직·장유, 대신·비거당상·양사장관 인견.

### 의미

인조 5년 3월 2일, 왜구 등 외교 교섭 업무를 맡은 관리 이정귀·이경직·장유 세 사람을 왕이 직접 인견하여 대신·비보거 당상·양사 수장 앞에서 보고를 들었다. 丁卯胡乱 직후 외교 일선 관리들의 활동이 왕에게 직접 보고되는 정기적 정무 일정이었다.
