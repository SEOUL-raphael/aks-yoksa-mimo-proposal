# 申冕이 各陵의 修理한 곳을 摘奸한 후에 들어옴

### 한글 번역

예조좌랑 신면이 여러 왕릉의 보수 공사장을 시범 검사한 뒤 들어왔다.

### 독음

예조좌랑 신면, 각릉 수리처 적간 후, 입래.

### 의미

인조 18년 9월 1일, 예조좌랑 신면이 각 왕릉의 보수 공사에 대해 부정이나 하자 유무를 시범 검사하고 궁으로 돌아왔다. 승정원일기의 간단한 기사로, 왕릉 보수 공사의 질서와 감독이 이루어졌음을 보여준다.

### 원문

```text
○ 禮曹佐郞申冕, 各陵修理處摘奸後, 入來。
```
