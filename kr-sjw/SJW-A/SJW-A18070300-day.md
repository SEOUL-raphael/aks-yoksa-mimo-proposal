## 昌慶宮에 머묾。常參과 經筵을 정지함

- 기사 ID: `SJW-A18070300-00100`
- 출처: https://sjw.history.go.kr/id/SJW-A18070300-00100

### 한글 번역

임금님께서 창경궁에 머무르시며, 상참과 경연을 정지하시다.

### 독음

상재창경궁 정상삼 경연

### 의미

인조 18년(1640년) 7월 30일, 인조가 창경궁에 거처를 옮겨 계시면서 날마다 거행하던 朝參(조삼)과 經筵(경연)을 중단한 사실을 전하는 짧은 기록이다. 창경궁은 원래 王子 시절의離宮(리궁)으로, 此後 창덕궁과 함께 동궐의 功能을 수행했다. 상참과 경연의 정지는 매우 드문 사안이므로, 당시 정치적 상황이나 인조의 健康 문제 등이 배경에 있었을 것으로 추정된다.

### 원문

```text
○ 上在昌慶宮。停常參·經筵。
```

## 韓好謙이 信伊를 拿來함

- 기사 ID: `SJW-A18070300-00200`
- 출처: https://sjw.history.go.kr/id/SJW-A18070300-00200

### 한글 번역

금부도사 한호겸이 반역죄인 김개자 신이를 붙잡아 데려왔다.

### 독음

금부도사 한호겸, 역적 김개자 신이를 나래하다.

### 의미

인조 18년 7월 30일, 금부도사 한호겸이 반역죄로 지목된 김개자 신이를 체포하여 데려왔다. 승정원일기에 기록된 짧은 언급으로, 이 사건의 구체적 배경이나 이후 재판 내용은 이 날 하루 분 기사에 보이지 않는다. 금부(禁府)는 조선의 법조기관이었고, 역적의 표시에서 이 사건이 정치적 성격을 지녔음을 짐작할 수 있다.

### 원문

```text
○ 禁府都事韓好謙, 逆賊金介子信伊拿來。
```

## 朴潢의 첫 번째 呈辭

- 기사 ID: `SJW-A18070300-00300`
- 출처: https://sjw.history.go.kr/id/SJW-A18070300-00300

### 한글 번역

대사간 박황이 첫 번째로 사직서를 올렸다. 사직이 허여되었다.

### 독음

대사간박황초도정사.급유.

### 의미

인조 18년(1640년) 7월 30일, 대사간 박황이 첫 번째 사직서를 제출하여 관직에서 내려오게 되었다. 初度는 해당 관원이 사직서를 올린 횟수를 나타내며, 이것이 첫 번째 사직임을 의미한다. 給由는 왕이 사직서를 받아들여 하사하는 것을 뜻한다. 대사간은 홍문관과 성균관 등의 교관(교수)을 겸임하던 높은 관직이었다.

### 원문

```text
○ 大司諫朴潢初度呈辭。給由。
```
