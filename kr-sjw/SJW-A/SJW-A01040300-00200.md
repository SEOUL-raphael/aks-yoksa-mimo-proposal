# 張顯光에게 다시 下諭하라는 전교

### 한글 번역

전교하기를, 치평(持平) 장현광에게 다시 하교한다.

### 독음

전일, 치평 장현광, 개위 하우.

### 의미

임금이 감찰관인 장현광에게 이전에 내렸던 지시를 다시 한 번 하교하라는 전교를 내렸다. '更爲'는 이전에 이미 하교한 내용을 재확인하거나 반복한다는 의미로, 장현광에게 해당 사항을 다시 주지시하는 것임을 나타낸다.

### 원문

```text
○ 傳曰, 持平張顯光, 更爲下諭。
```
