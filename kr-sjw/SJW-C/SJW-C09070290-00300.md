# 今春夏等 褒貶에 李克明이 中을 맞음

### 한글 번역

공조에서 금년 춘하등(봄·여름)褒貶(평가)에 대해, 장원서 별제 이극명을 중(中)으로 평정하였다.

### 독음

공조, 금춘하등포첨, 장원서별제 이극명, 중.

### 의미

1668년 7월 29일, 공조에서 금년 상반기 정기 인사 평가(褒貶)를 시행하여, 궁정의 동산과 조경을 관리하던 장원서 별제 이극명에게 중등의 서열(中)을 부여하였다.褒貶는文武官을 상중하로 평가하여 인사 좌천이나 승진에 반영하는 제도이다.

### 원문

```text
○ 工曹, 今春夏等褒貶, 掌苑署別提李克明, 中。
```
