# 李積 등에게 관직을 제수함

- 번역 모델: MiniMax-M2.7

### 한글 번역

정사에서 다음과 같이 관직을 제수하였다. 이적을 빙고별검에 임명하고, 조중움을 교하현감에 임명하며, 김득신을 예조좌랑에 임명하고, 정계음을 담양부사에 임명하고, 민유중을 겸임 서학교수에 임명하며, 민도를 군기첨정에 임명하고, 정시걸을 평양판관에 임명하고, 이돈림을 병조정랑에 임명하였다. 겸임 춘추수찬관 이돈상은 기사관 이역상과 생형제 사이로 서로 피하게 되어 수찬관을 감하고, 겸임 춘추기사관 이릭을 기주관에 보임하려 하였으나 기사관 이역과 생형제 사이로 서로 피하게 되어 기사관을 감하였다. 김시영과 원격은 모두 단위로 보임된 분차 겸임 동학교수에 임명하고, 이구징과 이는명은 모두 단위로 보임된 분차 겸임 남학교수에 임명하며, 정유제를 단위 교서부정자에 임명하고, 박세당을 단위 겸임 춘추관 기주관에 임명하며, 정동엽을 단위 겸임 춘추관 기사관에 임명하였다. 이조의 임명 제안 목록이다.

### 독음

유정. 이적을빙고별검이라하고, 조중움을교하현감이라하고, 김득신을예조좌랑이라하고, 정계음이담양부사라하고, 민유중을겸서학교수라하고, 민도를군기첨정이라하고, 정시걸을평양판관이라하고, 이돈림을병조정랑이라하고. 겸춘추수찬관 이돈상은기사업 이역상동생형제상피수찬관감하겸춘추기사업 이릭을기주관 이역동생형제상피기사업감하. 김시영·원격병단부분차겸동학교수, 이구징·이유명병단부분차겸남학교수, 정유제단부교서부정자, 박세당단부겸춘추관기주관, 정동엽단부겸춘추관기사관. 이조방단

### 의미

1663년 8월 1일 정사에서 다수의 관직을 제수하였다. 주요 임명으로는 이적을 빙고별검에, 조중움을 교하현감에, 정계음을 담양부사에, 이돈림을 병조정랑에 각각 임명하였다. 이돈상과 이릭은 각각 이역상·이역과 생형제 사이라는 이유로 기피되어 원래 맡으려던 수찬관·기사관 직을 감하게 되었다. 김시영·원격은 동학교수에, 이구징·이유명은 남학교수에 각각 보임되었으며, 박세당은 춘추관 기주관에, 정동엽은 춘추관 기사관에 단위 보임되었다.
