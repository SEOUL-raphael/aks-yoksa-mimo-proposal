# 李世長이 實錄을 考出하고 들어옴

- 기사 ID: `SJW-C06100010-00600`
- 왕대: 현종
- 날짜: 현종 6년(1665년 康熙(淸/聖祖) 4년) > 현종 6년 10월 > 현종 6년 10월 1일 > 李世長이 實錄을 考出하고 들어옴
- 번역 모델: MiniMax-M2.7

### 한글 번역

칙명을 받아 이세장이 실록을 조사하여 제시한 후, 들어왔다.

### 독음

봉교이세장, 실록고출후, 입래.

### 의미

1665년(현종 6년) 10월 1일, 이세장(李世長)이 왕의 명을 받아 실록을 조사考证하여 그 결과를 바치고 들어왔다. 승정원일기에서 특정 관원이 왕명을 수렴하고 일정한 조사 업무를 마친 뒤 입향한 일을 기재한 단순한 기록이다. '考出'은 실록 문헌을 뒤져 관련 사항을 찾아냈음을 뜻한다.

### 원문

```text
○ 奉敎李世長, 實錄考出後, 入來。
```
