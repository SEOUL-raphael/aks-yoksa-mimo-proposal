# 流星이 나타남

- 기사 ID: `SJW-C05020290-00200`
- 왕대: 현종
- 날짜: 현종 5년(1664년 康熙(淸/聖祖) 3년) > 현종 5년 2월 > 현종 5년 2월 29일 > 流星이 나타남
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-C05020290-00200

### 한글 번역

밤 둘째 경에, 유성이 북두성 위에서 나와 북쪽 하늘 끝으로 들어갔다. 모양이 항아리 같았고, 꼬리 길이가 오尺(약 1.5미터) 정도였으며, 색은 붉었고, 빛이 땅까지 비쳤다.

### 독음

야이경, 유통출북두성상, 입북방천제, 상태여병, 미장오척허, 색적,광조지.

### 의미

1664년 2월 29일 밤 중경(21~23시경)에 북두칠성 위에서 북쪽 하늘로 유성이 떨어졌다는 관측 기록이다. 항아리 모양에 붉은색에 빛이 땅까지 미치는 유성이었다.

### 원문

```text
○ 夜二更, 流星出北斗星上, 入北方天際, 狀如甁, 尾長五尺許, 色赤, 光照地。
```
