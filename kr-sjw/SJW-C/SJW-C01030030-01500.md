# 尹塏와 盧景垕가 寧陵의 曲牆을 修改한 뒤에 들어옴

- 기사 ID: `SJW-C01030030-01500`
- 왕대: 현종
- 날짜: 현종 1년(1660년 順治(淸/世祖) 17년) > 현종 1년 3월 > 현종 1년 3월 3일 > 尹塏와 盧景垕가 寧陵의 曲牆을 修改한 뒤에 들어옴
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-C01030030-01500

### 한글 번역

예조 정랑 인개와 선공감 역官 노경후가 영릉의 곡장을 수정한 뒤 들어왔다.

### 독음

예조정랑 인개, 선공감역 노경후, 영릉 곡장 수정 후 들어왔다.

### 의미

예조 정랑 인개와 선공감 역官 노경후가 선조의 능陵인 영릉의 곡장曲牆을 수정 작업을 마치고 입직入直하였다. 능의 보호 시설인 곡장修心事을 점검·수정한 것으로, 사직관료의 능묘 관리 업무를 보여주는 기록이다.

### 원문

```text
○ 禮曹正郞尹塏, 繕工監役盧景垕, 寧陵曲牆修改後入來。
```
