# 趙世煥의 處置와 관련하여 체직을 청하는 南二星의 상소

### 한글 번역

부응교 남이성이 상소를 올렸다. 요지는, 신이 정언 조세환의 처분에 있어 감히 태연할 수가 없으니, 관직을 내어줄 것을 청하여 공사와 사사를 편리하게 하고, 아울러 소회를 아뢰어 어가의 판단에 참고가 되기를 바라는 바이니, 임금에게 아뢴다.

### 독음

부응교 남이성이 상소하니 대략, 신이 정언 조세환의 처치에 감히 안연할 수 없으니, 관직을递递하여 공사를 사사를 편리하게 하소서. 겸하여 소회를 진술하여 재량을 미리备行하게 하소서. 입계하다.

### 의미

조선 숙종 9년(1668년) 10월 1일, 부응교 남이성이 정언 조세환의 어떤 처분에 불편함을 느끼고 자신이 맡은 관직을 내려줄 것을 요청하는 상소를 올렸다. 남이성과 조세환 사이에 일어난 사건이나 인사 논쟁과 관련된 상소로, 자신의 직을 떠나는 조건으로 조세환의 문제를 제기하며 궁정에 판단을 구한 것이다.
