# 藥房 등에서 안부를 물음

### 한글 번역

약방과 정원, 그리고 옥당에서 문안을 드렸다.

### 독음

약방·정원·옥당, 문안 위지

### 의미

1659년(현종 원년) 9월 1일, 약방과 정원, 옥당에서 임금의 안부를 묻는 문안 행위를 거행하였다. 왕의 건강 상태를 확인하고 안부를 전하는 국가 의례였다.
