# 崔文湜이 하직함

- 왕대: 현종

### 한글 번역

하직한다, 공주목사 최문질.

### 독음

하직, 공주목사 최문질

### 의미

공주목사 최문질이 관직上的 직무 일정을 마치고 하직하였다. 승정원일기에서는 해당 인물이 왕의 명을 받들어 수행하던 직무가 끝나 떠나는 사실을 기재한 것이다.
