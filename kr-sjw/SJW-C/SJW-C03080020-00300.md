# 藥房에서 大王大妃殿의 안부를 물음

### 한글 번역

대왕대비전에게 약방에서 구두로 문안했다. 전한回答说, 현재는 점점 호전되고 있으니, 앞으로는 문안하지 않아도 된다.

### 독음

대왕대비전, 약방 구전 문안. 답하기를, 금제는 차차 나아가고, 문안하지 말라.

### 의미

약방에서 대왕대비전의 건강을 문안한 기사. 대왕대비전은 현재 병이 차츰 나아가고 있는 상태라고 답신을 전했으며, 앞으로의 문안은 필요 없다는 취지를 전달했다.

### 원문

○ 大王大妃殿, 藥房口傳問安。答曰, 今則差愈, 勿爲問安。
