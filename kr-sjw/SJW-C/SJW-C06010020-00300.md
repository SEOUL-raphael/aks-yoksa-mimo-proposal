# 宋奎懰 등이 하직함

### 한글 번역

하직(下直)하였다. 청암찰방(靑巖察訪) 송규염, 안악군수(安岳郡守) 이여주.

### 독음

하직, 청암찰방 송규염, 안악군수 이여주

### 의미

승정원에서 근무를 마치고 하직한 사람으로, 청암찰방 송규염과 안악군수 이여주가 기록되었다. 하직은 관직에서 물러나는 것을 뜻한다.
