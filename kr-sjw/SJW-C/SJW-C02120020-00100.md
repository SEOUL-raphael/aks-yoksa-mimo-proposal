# 慶德宮에 머묾。常參과 經筵을 정지함

### 한글 번역

국왕이 경덕궁에 머물고, 常參와 經筵을 중지하다.

### 독음

상 재경덕궁. 정 상삼·경연.

### 의미

1661년 12월 2일. 현종 임금이 경덕궁에 거처하면서 왕의 일상 정시 朝參(상삼)과 經筵을 모두 중단하였다. 이는 특정 사건이나 왕의 건강 문제 등을 반영하는 것으로, 평소의 공식 일정이 잠시 중단된 것을 알리는 기사이다.
