# 沐浴한 뒤에 藥房 등에서 안부를 물음

### 한글 번역

대전에서 목욕을 마친 뒤, 약방과 정원과 옥당과 이품 이상의 벼슬아치와 육조와 대사간에게 안부를 물었다. 답하기를, 잘 알았다.

### 독음

大殿, 목욕후, 약방·정원·옥당·이품이상·육조·대사간 문안. 답일, 지도.

### 의미

1667년 윤4월 1일, 왕이 목욕을 마친 뒤 여러 관청과 고위 관료들에게 안부를 물었다는 기사로, 왕의 일상적인 건강 확인과 관련된 기록이다. 각 기관과 관료들이 왕의 안부를 묻고, 왕은 '알았다'고 답한 표준적인宫廷 문안 기록이다.
