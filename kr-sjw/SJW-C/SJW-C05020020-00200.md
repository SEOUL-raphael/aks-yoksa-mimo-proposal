# 太白星이 나타남

- 기사 ID: `SJW-C05020020-00200`
- 왕대: 현종
- 날짜: 현종 5년(1664년 康熙(淸/聖祖) 3년) > 현종 5년 2월 > 현종 5년 2월 2일 > 太白星이 나타남
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-C05020020-00200

### 한글 번역

오전 9시에서 11시 사이에, 태백성이 남서쪽 하늘에 나타났다.

### 독음

사시, 태백견어치지

### 의미

태백성(金星)이 낮 시간대에 남서쪽 하늘에서 관측되었다는 천문 기록이다. 태백성이 낮에 보이는 것은 드문 현상으로, 당시에는 불길한 징조로 해석되기도 하였다.

### 원문

○ 巳時, 太白見於未地。
