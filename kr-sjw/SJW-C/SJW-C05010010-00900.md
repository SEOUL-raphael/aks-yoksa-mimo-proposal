# 權愼을 拿囚하였다고 義禁府에서 아룀

- 기사 ID: `SJW-C05010010-00900`
- 왕대: 현종
- 날짜: 현종 5년(1664년 康熙(淸/聖祖) 3년) > 현종 5년 1월 > 현종 5년 1월 1일 > 權愼을 拿囚하였다고 義禁府에서 아룀
- 번역 모델: MiniMax-M2.7

### 한글 번역

義禁府에서 權愼을 붙잡아 가두었다고 보고하였다.

### 독음

금부, 권신 나수. 계.

### 의미

義禁府에서 정치범인 權愼을 체포·구금했음을 왕에게 공식적으로 보고한 기사이다. 1664년(현종 5년) 1월 1일자 승정원일기 기사로,義禁府가 왕에게 공식啟聞한 내용이다.
