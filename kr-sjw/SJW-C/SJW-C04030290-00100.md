# 昌德宮에 머묾。常參과 經筵을 정지함

### 한글 번역

임금이 창덕궁에 거재하시어, 일상 朝見과 經筵을 정지하셨다.

### 독음

상 재 창덕궁. 정상 참·경연.

### 의미

1663년(현종 4년) 3월 29일, 임금(현종)이 창덕궁에 거처하면서 일상 朝見과 經筵을 모두 중단하였다. 朝見은 정해진 시간에 대비한 일상 朝參(초참)과 달리 특별한 朝見(조견) 의례나 정시 朝參(조참)을 가리키는 것으로, 공식 일정의 전면 중단을 의미한다.

### 원문

```text
○ 上在昌德宮。停常參·經筵。
```
