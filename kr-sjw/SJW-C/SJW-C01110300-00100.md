# 慶德宮에 머묾。常參과 經筵을 정지함

- 왕대: 현종

- 번역 모델: MiniMax-M2.7

### 한글 번역

임금이 경덕궁에 머물러 있으므로 평소의 상참과 경연을 모두 중지하였다.

### 독음

상이 경덕궁에 머물러 상참과 경연을 정지하다.

### 의미

임금이 경덕궁에 거처하면서 상참(매일 아침 백관의 정기 참배)과 경연(임금의 유학 강습)을 일시 정지한 기사이다. 특별한 사정으로 경덕궁에서 기거하며 일상적인 궁정 일정까지 중단된 상황을 나타낸 짧은 기록이다.

○ 上在慶德宮。停常參·經筵。
