# 太白星이 나타남

### 한글 번역

사시(오전 9시~11시경)에, 태백성(金星)이 오지(남쪽 하늘)에 나타났습니다. 내하일기(관찰 기록).

### 독음

사시, 태백견어오지. 내하일기

### 의미

음력 6월 2일 사시(오전 9시~11시경)에 태백성(金星)이 남쪽 하늘에서 목격된 천문 현상을 기록한 기사이다. 태백성은 낮에 보이기가 드물어 중요하게 여겨졌으며, 내하일기에 기록하여 왕에게 보고된 사안이다.
