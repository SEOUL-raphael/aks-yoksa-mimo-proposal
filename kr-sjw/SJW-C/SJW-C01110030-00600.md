# 中殿의 안부를 물음

### 한글 번역

중전의 안부를 물었다. 대답하기를, '끝없는 은혜입니다.'

### 독음

중전 문안. 답왈, 망극.

### 의미

왕이 대비의 안부를 문안한 기록이다. 대비의 대답은 '끝없는 은혜'로 간략한데, 부모의 은혜가 끝이 없다는 의미의 관용적 표현으로, 문안 질문에 대한 겸손한 답으로 해석된다. 현종 1년 11월 3일의 짧은 기사이다.
