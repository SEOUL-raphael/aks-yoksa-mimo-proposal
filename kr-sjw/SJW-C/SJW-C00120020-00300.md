# 承政院에서 大王大妃殿 등의 안부를 물음

- 번역 모델: MiniMax-M2.7

### 한글 번역

정원이 대왕대비전에게 문안하였다. 답하기를, 알았다. 지금은 안녕하니, 문안하지 말라. 대비전과 대전에도 문안하였다. 답하기를, 알았다.

### 독음

정원, 대왕대비전 문안.답왈 지다.금즉 안녕, 물위문안.대비전·대전 문안.답왈 지다.

### 의미

조선 왕실의 문안 제도가 작동하는 장면이다. 정원(承政院) 관료들이 효도 차원에서 대왕대비전·대비전·대전에 문안을 올렸고, 대왕대비전은 현재 건강하니 더 이상 문안하지 말라고 답하였다. 대비전과 대전에는 답만 ‘알았다(知道)’로 돌아왔다. 현종 즉위 초반, 왕실의 건강과 안부를 살피는 일상적 왕실 예절이 기록된 기사이다.

○ 政院, 大王大妃殿問安。答曰, 知道。今則安寧, 勿爲問安。大妃殿·大殿問安。答曰, 知道。
