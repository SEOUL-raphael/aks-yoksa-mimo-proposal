# 현종 7년 5월 29일

- 날짜 코드: `SJW-C07050290`
- 왕대: 현종

## 無事

- 기사 ID: `SJW-C07050290-00200`
- 출처: https://sjw.history.go.kr/id/SJW-C07050290-00200

### 한글 번역

별다른 일 없음.

### 독음

무사.

### 의미

현종 7년(1666년) 5월 29일, 그날 하루 동안 의미할 만한 일이 없었음을 나타내는 승정원일기 일일마무리 기재이다. 이런 무기재(無記注) 표기는 왕실 기밀사항이 없었거나 특기할 사안이 발생하지 않았음을 의미한다.

### 원문

```text
○ 無事。
```

## 金佐明 등이 나감

- 기사 ID: `SJW-C07050290-00300`
- 출처: https://sjw.history.go.kr/id/SJW-C07050290-00300

### 한글 번역

원접사 김좌명과 문례관 정재희가 떠났다.

### 독음

원접사 김좌명, 문례관 정재희 출거.

### 의미

조선의 원접사 김좌명과 문례관 정재희가各自的 임무를 수행하기 위해 떠났다. 원접사는 청의 사신이나使者를 맞이하는 외교 담당관이고, 문례관은 사신에게 예물을 전달하거나 주관하는 실무 관료였다.

### 원문

```text
○ 遠接使金佐明, 問禮官鄭載禧出去。
```
