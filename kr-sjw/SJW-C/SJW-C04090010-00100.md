# 昌德宮에 머묾。常參과 經筵을 정지함

### 한글 번역

임금님께서 창덕궁에 머무르시고, 상참과 경연을 정지하셨다.

### 독음

상 재 창덕궁. 정 상참 경연.

### 의미

임금(현종)이 창덕궁에 거처하면서 일상 행정 행사인 상참과 경연을 중단한 기사. 상참은 오전에 이루어지는 임금의 일상早朝参会이고, 경연은 유학 경전 강의를 통한 왕의 학업을 말한다.
