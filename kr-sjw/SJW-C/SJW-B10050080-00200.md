# 朝哭 후 三提調가 四殿의 안부를 물음

- 번역 모델: MiniMax-M2.7

### 한글 번역

아침 곡(朝夕哭祭)을 행한 뒤에, 삼제조(三提調)가 네 전묘(四殿)를 인견하고 안부를 물었다. 대답하기를, '망극(罔極)합니다'라고 하였다.

### 독음

조곡후, 삼제조, 사전, 봉심문안. 답왈, 망극.

### 의미

1659년(효종 10년) 5월 8일, 효비왕후의상으로 조곡을 행한 뒤 삼제조가 사전(四殿: 효종과 태조비 한산부대왕비 이씨, 원종공신 정도공 이성계, 안동부원군 김서현 등의 사당)에 인견 문안하였다. '망극'은 상사 중임을 표시하는 경慕의 응답이다. 효비왕후(잇갈)의 졸시는 이전 달인 4월 25일로 추정된다.

### 원문

```text
○ 朝哭後, 三提調, 四殿, 奉審問安。答曰, 罔極。
```
