# 藥房에서 大王大妃殿 등의 안부를 물음

- 번역 모델: MiniMax-M2.7

### 한글 번역

대왕대비전과 왕대비전, 중궁전에 대해 약방에서 구두로 문안하였다. 답에 이르길, '알았다.'

### 독음

대왕대비전·왕대비전·중궁전, 약방구전문안. 답왈, 지도.

### 의미

1662년 8월 1일, 궁정의 의료·조제 기관인 약방에서 대왕대비전·왕대비전·중궁전 세 곳에 구두로 안부를 전했으며, 이에 대해 '알았다(知道)'고 회신한 기록이다. 왕실 내 빈위(비위) 세 곳을 대상으로 한 문안 절차가 이루어졌음을 보여준다.

### 원문

```text
○ 大王大妃殿·王大妃殿·中宮殿, 藥房口傳問安。答曰, 知道。
```
