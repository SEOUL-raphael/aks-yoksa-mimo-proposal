# 引見時 입시해야 할 三司의 인원을 牌招하여 入侍시킬 것인지를 묻는 承政院의 계

- 번역 모델: MiniMax-M2.7

### 한글 번역

정원에서 아뢰옵대니, 인견하라는 명이 이미 내리셨으니, 삼사의参謁官员들을 명찰하여 入侍시키겠사옵니까? 감히 올려小白합니다. 전교하시길, 오직 待漏院에 머물러 있으면서堂상階下만 入侍시키소서.

### 독음

정원계왈, 인견사 명하률。三사응입지원, 패초입사호? 감품。전왈, 지류대당상입사。

### 의미

현종 8년 11월 1일, 정원(承政院)이 삼사의 인원을 명찰하여 입시시키겠느냐고 여쭈었으나, 임금이堂上阶下만 입시시키고 하급관은 待漏院에 머물러 있으라 하신事例이다. 삼사참谒관의 일괄 入侍를要求하지 않고, 요직인 당상관만 선별적으로 인견에 참여시킨 단순한 조치를 보여준다.

### 원문

```text
○ 政院啓曰, 引見事, 命下矣。三司應入之員, 牌招入侍乎? 敢稟。傳曰, 只留待堂上入侍。
```
