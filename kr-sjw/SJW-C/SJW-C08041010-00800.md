# 요즘 日氣가 건조하므로 祈雨祭를 즉시 거행하라고 함

- 기사 ID: `SJW-C08041010-00800`
- 왕대: 현종
- 날짜: 현종 8년(1667년 康熙(淸/聖祖) 6년) > 현종 8년 윤4월 > 현종 8년 윤4월 1일 > 요즘 日氣가 건조하므로 祈雨祭를 즉시 거행하라고 함
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-C08041010-00800

### 한글 번역

임금이 말씀하셨다. “근래 날씨가 서늘하고 차가워서, 가뭄의 조짐이 다소 나타나고 있으니, 앞으로의 민생이 특히 매우 걱정된다. 기우제를 긴급히 거행하되, 매번 시기를 놓치는 한탄이 있게 된다. 내가 지금 여기 있는 바, 도내 산천에의祈雨祭와 경성에서의 기우제를 해당 부서에 명하여 즉시 거행하게 하라.”

### 독음

상 왈, 근래 일기 서랴, 보유 한점, 전두 민사, 수심 가려. 기우제, 림급 설행, 매유 후시 지탄의. 여방 재차, 도내 산천, 경중 기우제, 영해당조, 투즉 거행, 가야.

### 의미

현종 8년 윤4월 1일, 국왕이 근래 날씨가 싸늘하고 가뭄 조짐이 보이므로 민생이 걱정된다고 하면서, 기우제를 긴급히 거행하라고 지시하였다. 매번 기우제가 시기를 놓쳐서 한탄이 있었으므로, 국왕이 직접 거행하도록督責하는 내용이다.

### 원문

```text
○ 上曰, 近來日氣凄冷, 頗有旱漸, 前頭民事, 殊甚可慮。祈雨祭, 臨急設行, 每有後時之歎矣。予方在此, 道內山川, 京中祈雨祭, 令該曹, 趁卽擧行, 可也。
```
