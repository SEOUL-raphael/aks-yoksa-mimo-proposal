# 藥房에서 大妃殿의 안부를 물음

### 한글 번역

약방에서 대비전의 안부를 물었다. 대답하기를 '알았다'고 했다.

### 독음

약방, 대비전 문안. 답왈, 지도.

### 의미

약방에서 대비전의 안부를 묻자 대비전 측에서 알겠다고 답한 짧은 기사이다. 대비전은 전임 왕의 왕비로서 왕실 내 최고位女性에 해당하며, 약방은 왕실의 건강 관리와 관련된 관청이자 왕의 침실 역할을 하였다.
