# 趙翼의 차자

### 한글 번역

좌의정 조익이 차자를 올렸다. 대체로, 신이 예전에 겸임하고 있던 제조 직책을 해당 부서(사고)에 명하여 처리하게 해 달라는 내용이다. 이 상소는 입계되어 더 나아가 병조에 회부되어 처리되었다.

### 독음

좌의정 조익 차자. 대개 신이 예전에 겸임하던 제조 직임을 해당 사고에 명하여 처치하게 하라는 것. 입계. 사고(吏曹)에 내림.

### 의미

좌의정 조익이 자신이 예전에 겸임하던 제조 직임을 해당 부서에 이관하여 처리하도록 요청하는 차자를 올렸다. 효종 즉위년(1649년) 9월 1일에 입계되어吏曹에 회부되었다. 조익은 효종 초 중書門下府 소속 重臣으로 활동한 인물이다.
