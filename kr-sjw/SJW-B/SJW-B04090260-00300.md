# 上言에 대한 回啓를 속히 거행하라는 전교

### 한글 번역

전교한다. 근자에 상언에 대한 회계가 점점 뜸해지고 있으니, 각 해당 관청으로 하여금 신속히 처리하게 하라.

### 독음

전왈, 근일 상언 회계 희소, 영각해당사, 속위거행.

### 의미

효종 4년 9월 26일, 승정원에서 왕의 전교를 적은 기사이다. 백성이 임금에게 올린 상언에 대해 승정원이 회계(회답)하는 일정이 지나치게 느려졌음을 문제 삼아, 해당 관청에 신속한 집행을 명한 것이다. 왕이 승정원의 업무 처리 누락을 지적하고 재촉하는 사인에 해당한다.
