# 輪對에 尹大亨이 입시하여 司圃署의 公廨가 사람이 드문 벽촌에 있어서 날로 頹落하고 있으니 1~2명의 守直할 軍士가 없어서는 안되겠음을 논의함

### 한글 번역

윤대(임금이 관료를 불러 정사를 묻는 시간)에 사포별제 윤대형이 건의하기를, 본서(司圃署)의 몇 칸 되는 관사(公廨)가 외지고 인적이 드문 골목에 자리잡고 있는데, 지키는 사람이 없어 날마다 무너지고 있으니 군사 1~2명을 두지 않고는 안 될 것 같습니다, 하였다. 임금이 말씀하시길, 해당 부서에 알려 보내라 하셨다.

### 독음

윤대시, 사포별제 윤대형이 소계하기를, 본서 몇 칸의 공해가 벽항인희之地에 있어 지키는 사람이 없고 날로 무너지고 있으니, 군사 일삼명 없어서는 안 될 것 같다고. 상이 말씀하시길, 해당 조에 말하라.

### 의미

1655년 윤대(輪對) 시간에 사포서(식물 관리 관청)의 별제 윤대형이 입시하여, 사포서 관사가 사람이 뜸한 외진 골목에 있어 방임되고 있다고 보고, 그곳을 지키기 위해 군사 1~2명을 배치해야 한다고 건의하였다. 임금은 이를 해당 부처(吏曹·兵曹 등)에 전달하도록 답하였다. 관리하는 사람이 없어 낡은 관사가 황폐해지는 문제를 군사 배치로 해결하려는 실용적 건의 사안이다.

### 원문

○ 輪對時, 司圃別提尹大亨所啓, 本署數間公廨, 在於僻巷人稀之地, 而守直無人, 日漸頹落, 一二名軍士, 似不可無矣。上曰, 言于該曹。
