# 麟坪大君의 집에 親臨하여 致祭할 吉日을 6월 13일로 擇日했다는 禮曹의 계

- 기사 ID: `SJW-B09060010-01000`

- 번역 모델: MiniMax-M2.7

### 한글 번역

예조에서 인핸대군 댁에 직접 행차하여 제사 지낼 좋은 날을 6월 13일로 정하여 계를 올렸다

### 독음

예조, 인핸대군가 친림치제 길일, 유월十三일, 경

### 의미

효종 9년(1658년) 6월 1일, 예조에서 효종이 인핸대군의 집에 직접 가서 제사 지낼 날을 6월 13일로 잡아 관문(계문)을 올렸다. 효종이 서자 인핸대군의 사망 후 그를 위로하고 제사를 드리기 위해 직접 묘소나 집에 방문할 날을 정한 것이다.

○ 禮曹, 麟坪大君家親臨致祭吉日, 六月十三日, 啓。
