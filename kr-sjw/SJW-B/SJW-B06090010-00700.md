# 28일 거둥할 때 失禮한 通禮를 從重推考하라는 전교

- 기사 ID: `SJW-B06090010-00700`
- 왕대: 효종
- 날짜: 효종 6년(1655년 順治(淸/世祖) 12년) > 효종 6년 9월 > 효종 6년 9월 1일 > 28일 거둥할 때 失禮한 通禮를 從重推考하라는 전교
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-B06090010-00700

### 한글 번역

전교하기를, 지난달 스물여덟날 거둥할 때失礼를 저지른 통례에 대해, 아직도推察을 청구하지 않았느냐? 해당 방의 승지를 중하게 심사하라.

### 독음

전왈, 거월이십팔일거둥시, 실례통례, 상불청추야? 해당승지, 종중추고.

### 의미

지난달 28일 임금의 행차 시失礼를 저지른 승정원 통례 관직자에 대한 조사가 지연된 것을 질책하며, 해당 사무를 맡은 승지에게 중한 심사를 명한 효종의 전교. 通禮는 승정원의儀式 담당 정7품 관직이다.

### 원문

```text
○ 傳曰, 去月二十八日擧動時, 失禮通禮, 尙不請推耶? 該房承旨, 從重推考。
```
