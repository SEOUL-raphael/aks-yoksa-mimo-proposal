# 尹昌亨의 別軍職에 대해 兵曹에 전하라는 전교

### 한글 번역

전교를 내리기를, 사과(裨將) 윤창亨을 별군직(別軍職)에 제수하라는 내용을 병조에 알려 전하라.

### 독음

전왈, 사과 윤창亨 별군직 계하사, 언어병조

### 의미

효종 8년 9월 1일, 윤창亨을 별군직에 제수하는 사항이 계달되었다는 내용으로, 이를 병조에 전달하라는 왕의 전교이다. 승정원이兵曹에 해당 사항을 전달하는 과정에서 기록된 기사이다.

### 원문

```text
○ 傳曰, 司果尹昌亨別軍職啓下事, 言于兵曹。
```
