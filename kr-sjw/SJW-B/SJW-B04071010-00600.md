# 侍藥廳 등에서 慈殿의 안부를 물음

### 한글 번역

慈殿이 시약청과 정원, 옥堂에 왕의 안부를 물으셨다. 답하기를, 알겠다고 하였다.

### 독음

자전, 시약청·정원·옥당 문안. 답왈, 지도.

### 의미

효종 4년 윤7월 1일, 慈殿(효종의 어머니 인렬왕후)이 시약청과 정원, 옥堂에 왕의 안부를 문안하게 하였다. 각 직역에서는 '알겠다'고 답하였다. 이는 왕의 건강 관리를 위해太后가 직접 안부를 확인하던 일상적인 관행의 기록이다.
