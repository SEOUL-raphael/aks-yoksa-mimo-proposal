## 慶德宮에 머묾。常參과 經筵을 정지함

- 기사 ID: `SJW-B03070300-00100`
- 출처: https://sjw.history.go.kr/id/SJW-B03070300-00100

### 한글 번역

임금이 경덕궁에 계시었다. 매일 아침의 정례 朝參과 經筵을 중지하였다.

### 독음

상재경덕궁. 정상참·경연.

### 의미

1652년 7월 30일, 효종이 경덕궁에 거처하면서 일상적인 朝參 의례와 經筵 강의를 모두 중단하였다. 이는 효종비 明聖王后의 졸속으로 인해 궁中进行이 있었거나, 정치 일정이 변동된 상황을 반영하는 기록이다.

### 원문

```text
○ 上在慶德宮。停常參·經筵。
```

## 中宮殿의 안부를 묻는 藥房의 계

- 기사 ID: `SJW-B03070300-00200`
- 출처: https://sjw.history.go.kr/id/SJW-B03070300-00200

### 한글 번역

약방 도제조 벼슬신 정유성이 중궁전으로 직접 전해的问安을 올리다.連日에 걸쳐 약을 드린 뒤 어전의候가 어떠합니까. 답하기를, 약을 드린 뒤 증후와 땀이 완전히 나으며 나았으니, 더 이상問安을 하지 마소서.

### 독음

약방도제조신 정유성, 중궁전구전문안, 连일진약후, 옥후하여? 답왈, 진약지후, 증후여한기, 이미 진차유, 물위문안.

### 의미

효종 3년 7월 30일, 약방 도제조 정유성이 왕비 계시인 중궁전으로 직접 문안을 전하였다. 最近 여러 날 약을 내려온 뒤 증세와 땀이 이미 완전히 나으며 회복되었다고 답하였다. 따라서 더 이상 문안을 올리지 말라는 내용이다.

### 원문

```text
○ 藥房都提調臣鄭維城, 中宮殿口傳問安, 連日進藥後, 玉候何如? 答曰, 進藥之後, 症候與汗氣, 已盡差愈, 勿爲問安。
```
