# 昌德宮에 머묾。常參을 정지하고 晝講만 행함

### 한글 번역

임금이 창덕궁에 거처하시어 상참을 정지하시고, 오직 주강만을 행하시다.

### 독음

상재창덕궁, 정상참, 지주강

### 의미

효종 2년 10월 1일, 임금(효종)이 창덕궁에 계시어 아침에 신하를 끌어안아 정사를 의논하는 상참 의식을 멈추고, 낮에 행하는 주강(書經 독습)만 실시하였다. 효종 즉위 초 창덕궁 거처 전환기의 의례 축소 상황을 보여주는 기사이다.

### 원문

```text
○ 上在昌德宮。停常參, 只晝講。
```
