# 義禁府가 柳之芳을 拿囚하였다고 아룀

### 한글 번역

의금부에서 죄인 류지방을 붙잡아 투옥하였다고 아룁니다.

### 독음

금부, 죄인 류지방, 나수. 계.

### 의미

효종 7년 8월 1일, 의금부에서 죄인 류지방을 체포하여 옥에 가두었다는 내용의 계문이다. 류지방이 무슨 죄로 투옥되었는지는 이 짧은 기사에서 확인되지 않는다.

○ 禁府, 罪人柳之芳, 拿囚。啓。
