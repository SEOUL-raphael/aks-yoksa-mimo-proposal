# 藥房에서 大妃殿의 안부를 물음

### 한글 번역

대비전과 중전에게 약방에서 안부를 물었다. 답하기를, 알았다.

### 독음

대비전·중전, 약방 문안. 답왈,지도.

### 의미

약방에서 대비전과 중전의 건강 상태를 묻는 정기 문안 기사로, 해당 날짜의 대비전과 중전의 건강에 이상이 없었음을 나타낸다. 답변이 '知道(알았다)'로 간결한 것은 별다른 문제가 없음을 의미하는 표준 관행이다.

### 원문

```text
○ 大妃殿·中殿, 藥房問安。答曰, 知道。
```
