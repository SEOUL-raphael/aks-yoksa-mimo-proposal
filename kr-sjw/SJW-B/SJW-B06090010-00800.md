# 해당 通禮를 先罷後推하라는 전교

- 기사 ID: `SJW-B06090010-00800`
- 왕대: 효종
- 날짜: 효종 6년(1655년 順治(淸/世祖) 12년) > 효종 6년 9월 > 효종 6년 9월 1일 > 해당 通禮를 先罷後推하라는 전교
- 번역 모델: MiniMax-M2.7
- 출처: https://sjw.history.go.kr/id/SJW-B06090010-00800

### 한글 번역

전교하기를, 해당 통례 담당자는 먼저 파면한 뒤 추핵하라.

### 독음

전왈, 당해통례, 선패후추.

### 의미

효종 6년 9월 1일, 승정원에서 특정 통례 담당관에게 먼저 관직을 파면하고 이어서 추핵(탄핵 조사)하라는 전교를 내렸다. 通禮는 왕실 의례를 담당하던 종팔관杂직의 하나로, 관직이 낮았으나 실무적 역할을 수행했다. 先罷後推는 조선 왕조의 관료惩處 방식으로서, 파면으로 직위를 즉시 박탈한 후 탄핵 조사를 진행하는 이중 절차를 적용한 것이다.

### 원문

```text
○ 傳曰, 當該通禮, 先罷後推。
```
