# 權坽 등을 罷黜하였다는 江原道 暗行御史의 서목

- 번역 모델: MiniMax-M2.7

### 한글 번역

강원도 비밀 현지 점검을 시행한 어사의 서류에 이르길, 강릉부사 권녕과蔚진현령 윤여징을 파직시켰다.

### 독음

강원도 안행어사 서목, 강릉부사 권녕,蔚진현령 윤여징 파출사.

### 의미

1649년 12월 1일, 강원도에 파견된 안행어사(비밀 현지 점검御史)가 감사를 시행한 결과, 강릉부사 권녕과蔚진현령 윤여징을 파직시켰다는 서목(書目)이 보고되었다. 파출罷黜은 파직免職과 비슷하나 더 강한 조치가 포함된 상투적 처벌 수단이다. 강원도 관찰사가 아닌 별도 파견된 어사가 직접 보고한 것은 중앙 정부의 특별 감시 기능을 수행한 사례로, 사헌부의 통상 감사와는 다른 특별 행정 단속이었다.
