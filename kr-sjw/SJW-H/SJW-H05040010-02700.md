# 曺命集의 改差를 청하는 摠戎廳의 啓

### 한글 번역

엄기가 총용청의 말을 전하여 아뢴다. 본청 우부천총 조명집이 신체 이식이 갑작스럽게 위중하여 직임을 감찰하기 어려운 상황이라, 개차를 발령함이 어떠하겠습니까? 전교하시기를, 윤允하다.

### 독음

엄기, 총용청 언계하여 고하기를, 본청 우부천총 조명집, 신체 이식 갑작스러이 무겁고, 형세 감찰 임무하기 어려우니, 개차有何하오리잇가? 전교曰, 윤.

### 의미

총용청의 우부천총으로 재임 중이던 조명집이 갑작스러운 중병으로 직임을 수행할 수 없게 되자, 총용청에서 해당 관직의 개차를 요청한 내용이다. 어전에서 즉시 승인되었음을 보여준다.

### 원문

```text
○ 嚴耆, 以摠戎廳言啓曰, 本廳右部千摠曺命集, 身病猝重, 勢難察任, 改差, 何如? 傳曰, 允。
```
