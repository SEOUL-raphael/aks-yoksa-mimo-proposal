# 仕進하지 않은 沈能稷에 대해 즉시 牌招할 것을 청하는 趙琮鎭의 啓

- 번역 모델: MiniMax-M2.7

### 한글 번역

조종진이启迪하기를, 우승旨 심능직과 우부승旨 홍기섭이 오늘 근무에 나가지 않았으니, 모두 즉시牌招(출석 명령)하면 어떻겠습니까? 하였기에, 전지하기를, 윤허하였다.

### 독음

조종진启示일, 우승旨 심능직, 우부승旨 홍기섭, 금일 불위사진, 병즉패초, 하여? 전일, 윤.

### 의미

승정원 동부승지 조종진이 오늘 근무에 출근하지 않은 우승旨 심능직과 우부승旨 홍기섭을 즉시 출석 명령(牌招)할 것을 요청하여, 왕이 윤허한 기록이다. 사직하지 않은 수석 관리에게牌招를 요청하는 일상적 공문 처리 사안이다.

### 원문

```text
○ 趙琮鎭啓曰, 右承旨沈能稷, 右副承旨洪起燮, 今日不爲仕進, 竝卽牌招, 何如? 傳曰, 允。
```
