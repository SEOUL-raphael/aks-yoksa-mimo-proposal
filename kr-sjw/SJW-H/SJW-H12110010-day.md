# 순조 12년 11월 1일

- 날짜 코드: `SJW-H12110010`
- 왕대: 순조

## SJW-H12110010-00600

- 기사 ID: `SJW-H12110010-00600`
- 출처: https://sjw.history.go.kr/id/SJW-H12110010-00600

### 한글 번역

전교를 이지연에게 내리기를, 전향승지를 시켜 경모궁에 신속히 내려가 직접 살피고 문제를 조사해 오게 하였다.

### 독음

전교(傳敎)를 이지연에게 전달한다. 전향승지를 급히 경모궁에 보내어奉審摘奸하도록 명이 내렸다.

### 의미

순조 시대 왕이 승정원 교서관 이지연을 통해 전향승지에게 경모궁을 긴급 방문하여 모심기(奉審) 및 적간(摘奸: 문제 조사)을 행하도록 지시한 교지이다. 왕의 직접 서명 없이 이지연을 통한 전교 형태로 발부되었으며, 경모궁(순조의 아버지 정조의 사당)의 안녕 여부와 관리 상태 점검을 명령한 것이다.

### 원문

```text
○ 傳于李志淵曰, 傳香承旨馳詣景慕宮, 奉審摘奸以來。
```

## 藥房副提調가 湯劑를 가지고 來待한다는 朴宗京의 啓

- 기사 ID: `SJW-H12110010-00700`
- 출처: https://sjw.history.go.kr/id/SJW-H12110010-00700

### 한글 번역

박종경이 아뢰었다. 약방 부제조가 탕제(민간 약초 달인 물)를 가지고 와서 대기하고 있다고 한다. 전교하기를, "입력(봉입)하라."

### 독음

박종경계일, 약방 부제조 지탕제 내타 대지언전왈, 봉입.

### 의미

순조 12년 11월 1일, 약방 부제조가 국왕의 치료나 건강을 위해 준비한 탕제를 들고 와서 대기하고 있음을 승정원 도사 박종경이 보고하였다. 이에 국왕이 해당 물품을 제출하라는 전교를 내렸다. 왕실의 건강 관리와 의료 실무가 일상적으로 운영되던 일상 사적인 기록이다.

### 원문

```text
○ 朴宗京啓曰, 藥房副提調持湯劑來待矣。 傳曰, 封入。
```

## 초 5일에 朝參을 시행할지를 여쭙는 李志淵의 啓

- 기사 ID: `SJW-H12110010-00800`
- 출처: https://sjw.history.go.kr/id/SJW-H12110010-00800

### 한글 번역

이지원이 아뢴다. 내일(다음날) 5일은 조참하는 날입니다, 삼가 여쭙습니다. 전교하기를, 알았다.

### 독음

이지원 계曰, 내 초五日, 조참 일차의니, 감히 물으니이다. 전해曰, 지도하다.

### 의미

승정원 관료 이지원이 다음 달 5일이 조참일정에 해당한다며 시행 여부를 아뢴것이다. 임금이 이를 수락하는 짧은 왕命이다. 조참은 신하들이 아침에 궁궐에 모여 임금의 안부를 여쭙는 공식 의례이다.

### 원문

```text
○ 李志淵啓曰, 來初五日, 朝參日次矣, 敢稟。 傳曰, 知道。
```

## SJW-H12110010-01000

- 기사 ID: `SJW-H12110010-01000`
- 출처: https://sjw.history.go.kr/id/SJW-H12110010-01000

### 한글 번역

좌부승지 한긍려가 소명(召命)에 불응하여 파직시키라는 전지를 윤정열에게 전달하되, '지추(只推)하라'고 했다.

### 독음

이 좌부승지 한긍려가패불진파직전문, 전어윤정열왈, 지추

### 의미

승정원 좌부승지 한긍려가 왕의 소환 명령에 불응하여 본래 파직 처분을 받아야 하였으나, 왕은 처벌을 경감하여 경고(只推)에 그치게 하였다. 이 내용은 승정원 도사 윤정열에게 전달되었다.

### 원문

```text
○ 以左副承旨韓兢履牌不進罷職傳旨, 傳于尹鼎烈曰, 只推。
```

## SJW-H12110010-01500

- 기사 ID: `SJW-H12110010-01500`
- 출처: https://sjw.history.go.kr/id/SJW-H12110010-01500

### 한글 번역

윤정열에게 전지하기를, 도감의 군기 제조 공사가 이제 모두 완공되었으니, 감독과 주도, 장교와 장인 및募軍 등은 별도의 명단에 적어 올려라.

### 독음

전유윤정열왈, 도감군기조성지역, 금이미완, 감동장관장모등, 별단서입.

### 의미

순조 12년 11월 1일 승정원이 윤정열에게 도감의 군기 제조 공사가 완공되었음을 보고하고, 관련 관리와 장인 등의 인원을 별도 명단으로 작성하여 보고하도록 지시한 사항이다.

### 원문

```text
○ 傳于尹鼎烈曰, 都監軍器造成之役, 今已畢完, 監董將官匠募等, 別單書入。
```
