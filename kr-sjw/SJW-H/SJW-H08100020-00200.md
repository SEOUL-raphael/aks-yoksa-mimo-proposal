# 王大妃殿 등에게 承旨를 보내 안부를 물음

- 번역 모델: MiniMax-M2.7

### 한글 번역

왕대비전과惠慶宮(혜경궁)·嘉順宮(가순궁)에 승지를 보내어 아침과 저녁으로 안부를 물었다. 답하기를, '알았노라' 하셨다.

### 독음

왕대비전·혜경궁·가순궁 견승지, 조석문안. 답왈, 지도.

### 의미

순조 8년 10월 2일, 왕이 왕대비전과惠慶宮(순원왕후)·嘉順宮(훤빈)에게 승지를 보내 아침저녁으로 문안하였고, 각 궁에서는 '알았다'고 답하였다. 이는 왕이 왕실 상위 여성들의 건강을 신경 쓰며 안부를 전하던 왕실 의례의 일환이다.
