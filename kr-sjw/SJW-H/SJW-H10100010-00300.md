# 藥房에서 中宮殿에게 안부를 물음

### 한글 번역

중궁전에서 약방에 구두로 안부를 전하여 물었다. 답하길, '알았다.'

### 독음

중궁전 약방구전문안 답왈지도

### 의미

순조 10년 10월 1일, 중궁전(왕비의 궁전 또는 왕비)의 안부를 약방에 구두로 전하여 확인하였다. 약방에서 '알았다'는 답을 하였다. 이는 왕실 내 건강 문안의 일종으로, 일상적인 왕실 통신 절차에 해당하는 짧은 기록이다.
