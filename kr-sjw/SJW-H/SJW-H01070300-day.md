## 昌德宮에 머묾. 常參과 經筵을 정지함

- 기사 ID: `SJW-H01070300-00100`
- 출처: https://sjw.history.go.kr/id/SJW-H01070300-00100

### 한글 번역

임금님께서 창덕궁에 거재하시어, 상참과 경연을 정지하시다.

### 독음

상재창덕궁, 정상참·경연

### 의미

순조 1년 7월 30일, 임금님께서 창덕궁에 계시면서 정기적으로 신하를 만나는 상참 의식과 경전 강독을 듣는 경연 수업을 모두 중단하였다. 이는 특별한 사정이 있거나 일상 공무 일시 중단을 알리는 기사이다.

### 원문

```text
○ 上在昌德宮。停常參·經筵。
```

## 藥房에서 大王大妃殿 등에게 안부를 물음

- 기사 ID: `SJW-H01070300-00300`
- 출처: https://sjw.history.go.kr/id/SJW-H01070300-00300

### 한글 번역

약방에서 대왕대비전·왕대비전·혜경궁·가지순궁에게 구두로 안부를 물었다. 그에 대한 답변은 '알았다'였다.

### 독음

대왕대비전·왕대비전·혜경궁·가지순궁, 약방에서 구전으로 문안하였다. 답은, 알았다.

### 의미

순조 1년 7월 30일, 약방에서 궁정의 상위 수빈들에게 안부를 구두로 전했으며, 모두 알았다는 답변을 받았다. 구전문안은 약방이라는 직제 기관이 왕명을 받아 시행하는 정기적 문안 절차다.

### 원문

```text
○ 大王大妃殿·王大妃殿·惠慶宮·嘉順宮, 藥房口傳問安。 答曰, 知道。
```
