# SJW-G18060010-00400

- 왕대: 정조

- 번역 모델: MiniMax-M2.7

### 한글 번역

이면경에게 전교하기를, 이병방 승지가 세초를 가지고 입시하라.

### 독음

전어이면경왈, 리병방 승지, 지세초 입시.

### 의미

정조 18년 6월 1일, 왕이 승지 이면경에게 이병방 승지에게 세초를 가지고 입시하도록 전교했다. 세초는 해당 직전 1년간 임명·전직·삭감된 관리 명단으로, 정조 연간 호조와 병조 관련 인사를 정리한 문서일 가능성이 높다. 왕이 특정 승지에게 직접 지시하며 입시 명령을 내린 것은 정기 심사 혹은 긴급 인사 조정을 앞두고 있음을 보여준다.
