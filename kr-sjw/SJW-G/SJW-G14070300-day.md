## 昌德宮에 머묾. 常參과 經筵을 정지함

- 기사 ID: `SJW-G14070300-00100`
- 출처: https://sjw.history.go.kr/id/SJW-G14070300-00100

### 한글 번역

임금님께서 창덕궁에 거처하시어 상참과 경연을 정지하셨다.

### 독음

상재창덕궁, 정상참경연

### 의미

정조 14년 7월 30일, 임금(정조)이 창덕궁에 거처하면서 일상적인 아침 朝參인 상참과 왕의 학문修養을 위한 강좌인 경연을 모두 중지하였다. 이는 특별한 사정이 있거나 건강 이상等原因으로 왕이 궁궐에서 공식적인 朝會와 학업을 잠시 중단한 것을 알리는 기사이다.

### 원문

```text
○ 上在昌德宮。停常參·經筵。
```

## 內閣 등에서 안부를 물음

- 기사 ID: `SJW-G14070300-00200`
- 출처: https://sjw.history.go.kr/id/SJW-G14070300-00200

### 한글 번역

임금이 대궐을 나서서 종묘에 다녀와 재실에 들어간 뒤, 내각과 정원과 옥당과 약방에서 구두로 문안 인사를 올렸다. 답하길, 알았다.

### 독음

대가 예 종묘, 입재실 후 내각·정원·옥당·약방 구전문안. 답왈, 지도.

### 의미

정조 14년 7월 30일, 임금이 종묘에 행幸(하임)하여 제사完毕后 재실에 들어갔다. 왕의 안부를 살피기 위해 주요 관청(내각·정원·옥당·약방)에서 순차로 구두 문안(口傳問安)을 올렸고, 임금은 '알았다(知道)'라고 답하신 내용을 승정원에서 기재한 기록이다. 왕의 제사 참여 후 문안 제도와 왕의 응답 형식을 보여주는 기사.

### 원문

```text
○ 大駕詣宗廟, 入齋室後, 內閣·政院·玉堂·藥房口傳問安。答曰, 知道。
```

## 內閣에서 안부를 물음

- 기사 ID: `SJW-G14070300-00300`
- 출처: https://sjw.history.go.kr/id/SJW-G14070300-00300

### 한글 번역

전알(先祖参拜) 예식을 마친 뒤, 내각과 승정원과 홍문관과 약방에서 구두로 안부를 물었다. 답하기를, '알았다.'

### 독음

전알罢後, 내각·정원·옥당·약방 구전문안. 답일,지도.

### 의미

정조 14년 7월 30일, 왕이 선조의 묘소에 참배하는 전알 의식을 마친 뒤 내각·승정원·홍문관·약방 등 핵심 관청에서 차례로 왕의 안부를 묻는 문안 행렬이 있었다. 왕은 이를 수看一看고 답하였다. 이러한 구전문안은 왕의 일상 동정과 건강 상태를 살피는 궁정의 공식 의전 절차였다.

### 원문

```text
○ 展謁罷後, 內閣·政院·玉堂·藥房口傳問安。答曰, 知道。
```
